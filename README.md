## 自己截屏

桌面端会按窗口自动适配。用“小图模式”降低图片区的高度，用“大字阅读”单独放大作品说明，用“小一点”和“大一点”调整整张画面。进入“截图模式”后将鼠标移开，退出按钮会自动隐去；按 Esc 返回，也可以移动鼠标或触摸页面唤出按钮。手机端采用可滚动的阅读布局。

## 来源与运行

原作文字、署名和图像来自[桥见原站](https://bridge-sense-ai-community-2026.shiyuzhao-super.chatgpt.site/)。对照页分别注明学生原作、课堂示意、读者追问和迁移任务。社区中新增的演示投稿保存在当前浏览器。

本仓库从 main 分支根目录发布 GitHub Pages。首页与对照页是独立静态页面。社区的静态入口和构建所需文件位于 community 目录。
